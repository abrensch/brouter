# Environmental considerations

Environmental considerations (penalties for traffic, noise, town, no river, no forest) are possible due to the creation of pseudo tags during the processing of OSM data by spatial SQL queries in [brouter.sql](https://github.com/abrensch/brouter/blob/master/misc/scripts/mapcreation/brouter.sql). Using the link, you can ask AI how it is currently calculated and how to use it.
