### Contributing

There are several themes to contribute:

- the library
- the profiles
- the Android app
- the data generation

The procedure for contributing is always the same:
Check the repository to see if your problem has already been discussed, addressed, or remains unchanged.
Then add an issue.

Please see the {git docs](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project) for more detailed informations when you like to do more then a notice on a problem.

And please read and respect the [developer guide](docs/developers/delevoper_guide.md)
